💖 Introducing My Self-Built Project: Friendship Checker | C++ OOPs

I'm excited to share a small project that I built from scratch — Friendship Checker, a fun application that evaluates friendship using different parameters! 🚀

The idea was to combine my C++ programming knowledge with logical thinking and turn it into an interactive project.



✨ Key Features:

👥 Takes two names as input and calculates a Destiny Score based on common letters.

🤝 Evaluates friendship using comfortability, trust, understanding, and time spent together.

📊 Calculates a Friendship Rating, Bond Score, and Grade.

💬 Displays friendship status, motivational quotes, and personalized advice.

✅ Includes input validation to ensure scores remain within the specified ranges.

🌐 Developed an HTML, CSS, and JavaScript version with an interactive interface.



🛠️ Technologies Used:

C++, HTML\CSS, OOPS



📚 OOP Concepts I Practiced:

Classes and Objects, Encapsulation, Constructors, Friend Function, Friend Class, Static Data Members and Member Functions



This project helped me practice programming logic, conditional statements, functions, and OOP concepts while exploring how a C++ idea can be presented through a web interface.

For me, this is more than just a friendship calculator — it's a step forward in my journey as a developer. ❤️

I'm looking forward to building more projects, learning new technologies, and improving my problem-solving skills!
